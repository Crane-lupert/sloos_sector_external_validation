# PHASE4C_SPEC — SLOOS 논문 (v3) 용 메커니즘 검정과 표 구성

고정일 2026-11-21. **대손·충당금 결과 변수를 보기 전에** 썼다. 공통 지시는 `../PHASE4_PROTOCOL.md`. 메인 스레드가 직접 수행한다. 산출물은 `paper_v3/`.

## 1. 왜 하는가

4차·4B 가 보인 것은 수익률이다: CRE 순긴축이 높게 공표된 분기 뒤에 CRE 비중이 높은 은행이 덜 오른다. 논문에는 그 경로가 필요하다. 가설: 조사에서 CRE 긴축이 높게 나온 뒤에는 **CRE 비중이 높은 은행의 대손이 실제로 더 늘어난다** (긴축은 은행들이 본 부실 신호이고, 시장은 그것을 은행별 노출에 맞춰 늦게 반영한다).

## 2. 메커니즘 검정 M1 (결과 전 고정)

- 표본: 4차의 은행 표 (`phase4/out/s1_bank_table.parquet`) 의 (은행지주사, 공표) 관측. 2000–2024, 주 유니버스 (`screen`).
- 결과 변수: 공표 `r` 뒤에 끝나는 **다음 네 분기**의 (i) 순대손 (charge-offs − recoveries: BHCK4635 − BHCK4605) 합계, (ii) 대손충당금 전입 (BHCK4230) 합계를, 신호에 쓴 보고 분기의 총대출 (BHCK2122) 로 나눈 값 (%). Y-9C 의 손익 항목은 연초 누계라 분기 차분으로 분기 흐름을 만든다 (1분기는 누계 그대로).
- 회귀: `결과(i, r) = 공표 고정효과 + 범주 비중 (CI·CRE·CC·OC) + b × [CRE 비중(i) × (N_CRE(r) − 표본 평균) / 10] + 오차`. 표준오차는 공표와 은행의 양방향 군집 (결과 창이 겹치므로). **예상 부호 b > 0.**
- 판정: 주 통계량은 순대손의 b. 예상 부호이고 |t| ≥ 1.96 이면 "메커니즘과 부합", 아니면 "부합하지 않음" 으로 논문에 그대로 적는다. 충당금 판과 은행 고정효과를 더한 판은 함께 보고한다.
- 네 분기가 2024-12 뒤로 넘어가는 공표는 뺀다.

## 3. 논문 표 구성 (새 검정 아님 — 이미 있는 결과의 정리)

T1 표본·요약 통계 / T2 사전 고정 검정 (BT 5분위, 2000–2024·1991–2000·합침) / T3 CRE 경로 (시계열 회귀: 발견 구간·확인 구간·합침·위기기 제외·직전 스프레드 통제·직전 조사) / T4 은행 단위 패널 (범주별 상호작용) / T5 메커니즘 (M1) / T6 구현 (가중·비용·한 해 제외·2025 기록) / 부록: 통과하지 못한 사전 고정 검정 (공표일 반응, 시장 타이밍) 과 이전 판과의 관계.

T2·T3·T4·T6 의 수치는 4차·4B 와 메인 스레드 확인에서 이미 계산한 값을 같은 정의로 다시 뽑는 것이다. 정의를 바꾸지 않는다. 합친 표본 (1991–2024) 의 패널 회귀처럼 두 구간을 잇는 계산은 "기술 통계" 로 표기한다.
